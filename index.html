Privacy & Security Notice

  1. Two-Person Temporary Rooms: VanishText is engineered strictly for private, temporary, 1-to-1 text conversations. No group chats, public directories, or user accounts exist.
  2. Automatic 15-Minute Message Deletion: Every message automatically disappears from both users' chat screens exactly 15 minutes after it was sent. Each message runs on its own independent timer.
  3. 1-Hour Room Lifespan: Each room expires exactly 1 hour after its creation using real elapsed time. Upon expiration, both participants are disconnected, chat interfaces are cleared, the invitation code is invalidated, and the room is permanently disabled. Never reactivated.
  4. Zero Persistent Chat History: Chat messages exist solely in volatile memory during an active session. Messages are never saved to localStorage, sessionStorage, IndexedDB, databases, persistent queues, or chat logs.
  5. Genuine End-to-End Encryption: Messages are encrypted on the sender's device using authenticated AES-256-GCM before transmission and decrypted only on the recipient's device. Ephemeral ECDH keypairs (P-256) are generated per session and destroyed on departure.
  6. Honest Privacy Disclosures: We do not claim that every trace is erased from all systems worldwide. Unavoidable infrastructure metadata (including IP addresses, connection timestamps, and ICE routing packets) is processed by external signaling brokers (PeerJS Cloud / STUN servers) and may be retained in provider network logs. Furthermore, OS-level memory pagefiles, hardware caches, and recipient screen observation or capture cannot be prevented by any web application.
  7. Strict Text Only Policy: Images, videos, voice recordings, attachments, and camera/mic permissions are completely excluded.
